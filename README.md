# Creditworthiness Prediction Using Machine Learning

## 📌 Overview
This project predicts the creditworthiness of loan applicants using the Random Forest Classifier. It analyzes customer information such as income, debt, and payment history to determine whether a customer is creditworthy and eligible for loan approval.

## 🚀 Features
- Predicts whether a customer is creditworthy
- Uses the Random Forest Classifier
- Analyzes income, debt, and payment history
- Simple and easy-to-understand implementation
- Built using Python and Scikit-learn

## 🛠️ Technologies Used
- Python
- Scikit-learn
- Pandas

## 📊 Dataset
A sample dataset created using Pandas with the following features:
- Income
- Debt
- Payment History
- Creditworthy (Target)

## ▶️ How to Run
1. Clone this repository.
2. Install the required libraries:
   ```
   pip install -r requirements.txt
   ```
3. Run the program:
   ```
   python creditworthiness_prediction.py
   ```
